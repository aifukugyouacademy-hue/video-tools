Video Bitrate & File Size Calculator

Find out how large an export will be, or which bitrate fits a size limit. Everything is calculated in your browser; no video is uploaded.

How it works

File size = (video bitrate + audio bitrate) × duration ÷ 8. Bitrates are in bits per second, so dividing by 8 turns bits into bytes. This calculator uses decimal units (1 MB = 1,000,000 bytes), the same as macOS Finder and most upload limits. Windows Explorer shows binary units, so the same file looks about 5–7% smaller there.

With variable bitrate (VBR) exports, the real file can land above or below the estimate because the encoder spends more bits on busy shots. When you must stay under a hard limit, keep the safety margin at a few percent. Container overhead (MP4/MOV) is usually under 1% and is not included.

Quick start

Pick a tab, enter the duration and bitrates (or a size limit), and read the result. The presets fill in YouTube's recommended video bitrates.
